Title: SIAMBA: A Pseudo-Siamese Mamba-based Deep Learning Network for Multimodal Flood Change Detection
Authors: Muhammad Fasih Ishfaq, Giulio Weikmann, Lorenzo Bruzzone
ID: 2611.30938
URL: https://arxiv.org/abs/2611.30938

Abstract:
Flood change detection from bi-temporal multispectral and synthetic aperture
radar (SAR) images is essential for rapid disaster response. In this context,
Sentinel-2 multispectral imagery provides discriminative spectral observations,
whereas Sentinel-1 SAR provides weather-independent structural information.
Using these modalities jointly requires modelling temporal evidence while
accounting for cross-modal heterogeneity. In particular, change detection is
complicated by cloud contamination, illumination variability, acquisition
geometry and speckle, and heterogeneous land-cover responses. To address these
challenges, we propose SIAMBA, a pseudo-siamese Mamba-based network for bi-
temporal flood change detection from paired Sentinel-1 and Sentinel-2
observations. SIAMBA uses dedicated modality-specific encoders with dual-pooling
squeeze-and-excitation recalibration and selective state-space processing for
long-range spatial context. A gated cross-modal change module derives absolute,
signed, and relative log-ratio differences at multiple semantic levels, and
attention-refined skip connections support progressive multi-scale decoding.
Experiments are carried out on OMBRIA benchmark, which includes an independent
test set and geographically diverse subsets in France, Albania, Guyana, and
Timor. SIAMBA achieves 81.98% IoU, and 93.57% OA on the independent test set,
reaching the highest values in the considered comparison. It also provides the
highest unweighted average IoU and OA across four regional subsets spatially
disjuncted. These results indicate that combining selective state-space
contextual modelling with gated multiscale discrepancy learning effectively
improves flood change mapping across the evaluated geographic settings.
