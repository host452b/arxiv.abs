Title: EventSSM: Causal Spatial-State Modelling for Asynchronous Events Event-Depth Estimation
Authors: Sadiq O. Macaulay, Dipon Ghosh, Hadfield Simon
ID: 2611.31720
URL: https://arxiv.org/abs/2611.31720

Abstract:
Event cameras report asynchronous brightness changes, yet metric-depth
supervision is typically available only at sparsely sampled reference
timestamps. Aggregating events into frame-like representations simplifies
learning but can obscure the fine-grained temporal structure of the original
event stream. We introduce EventSSM, a causal spatial-state framework for event-
associated metric-depth estimation using a recurrent memory updated by
chronological event packets. To bridge asynchronous predictions and frame-time
supervision, predicted event depths are geometrically transported using
calibrated camera poses and differentiably rendered at reference timestamps.
Benchmark evaluations demonstrate improvements over established event-depth
methods across multiple depth-error measures. Controlled ablations further
examine cross-modal initialization, temporal recurrence, individual state,
readout, and supervision components, and packet subdivision. Together, these
findings establish EventSSM as an effective framework for causal event-
associated metric-depth estimation, combining persistent spatial context with
physically timed state retention.
