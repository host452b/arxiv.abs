Title: Simultaneously Boosting Efficiency and Capability for Linear Attention via Adaptive Channel Compression and Activation Purification
Authors: Senqi Guan, Xianchao Zhang, Moyan Tian, Linlin Zong, Wenxin Liang, Xinyue Liu
ID: 2611.32877
URL: https://arxiv.org/abs/2611.32877

Abstract:
Self-attention's quadratic complexity constitutes a core bottleneck for Vision
Transformers (ViTs). Existing efficiency-oriented optimizations, including
softmax-based and linear attention (LA) variants, generally compromise model
representational capacity, leading to inevitable performance degradation. We
propose a novel linear attention which alleviates this efficiency-capability
dilemma. For the first time, we embed an Adaptive Channel Compression and
Activation Purification (ACCAP) mechanism into the QKV projection of linear
attention, which enables the model to retain high-dimensional feature
information while performing computations with reduced channels. We further fuse
a focused kernel function and a self-gating module into ACCAP to construct a
lightweight linear attention module (ACCAP-LA). Our theoretical analysis shows
that, compared to standard linear attention, ACCAP-LA reduces the attention
module's parameter count by 79.17% and FLOPs by 77.5%. Extensive experiments
demonstrate ACCAP-LA's effectiveness: when applied to ViT, it achieves 79.4%
Top-1 accuracy on ImageNet-1K with only 5.8M parameters, and more notably, it
boasts strong cross-architecture compatibility, boosting EfficientViT-b1 and
PVT-T by 3.3% and 3.4% respectively.
