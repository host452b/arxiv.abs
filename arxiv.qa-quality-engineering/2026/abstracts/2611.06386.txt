Title: Shoot on (Core)Sight: Re-enabling Secure Debug on the RP2350 with Photon-Emission Microscopy and Laser Fault Injection
Authors: Antoine Plin
ID: 2611.06386
URL: https://arxiv.org/abs/2611.06386

Abstract:
Fault-resistant policy storage does not guarantee fault-resistant enforcement.
We demonstrated this distinction on the RP2350A4 using differential photon-
emission microscopy (PEM) and laser fault injection (LFI). PEM narrowed the area
for laser scanning, which found two sites where pulses set the DEBUGEN bits
enabling core~1 Secure debug. An online attack sequence using only Serial Wire
Debug (SWD) feedback restored sustained access. After rescue reset, the sequence
recovered a 128-bit test secret. This reset reloads the secret's runtime page
lock from a stored policy that permits Secure reads and prevents user firmware
from tightening the lock.
