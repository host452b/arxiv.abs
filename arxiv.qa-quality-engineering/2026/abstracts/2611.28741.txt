Title: VEGA: A Scalable Software-Hardware Co-design for Genome Alignment using RVV Extension
Authors: Weihong Xu, Shijie Xu, Qunyou Liu, Giovanni Ansaloni, Cheng Zhuo, David Atienza
ID: 2611.28741
URL: https://arxiv.org/abs/2611.28741

Abstract:
Dynamic programming (DP)-based genome sequence analysis is fundamental to
computational genomics, but it remains computationally intensive as genomic data
volumes continue to outpace Moore's Law. Existing hardware accelerators often
sacrifice programmability and scalability across diverse alignment algorithms.
In this work, we present VEGA, a scalable software-hardware co-design that
accelerates genome alignment using RISC-V Vector extensions. VEGA introduces
specialized vector instructions and three key innovations: a Forefront
Stationary dataflow that minimizes off-chip memory access, intersequence
parallelism that maximizes SIMD lane utilization, and custom ISA extensions that
accelerate core alignment operations. Evaluations show that VEGA achieves up to
15.1x and 9.7x speedups for Edit Distance and Smith-Waterman algorithms over the
Ara2-RVV vector baseline, sustaining 10.2x and 6.7x gains for 10kbp sequences.
Post-synthesis results indicate only 1.0% area overhead compared to a standard
RISC-V core, with performance-per-area efficiency rivaling specialized ASICs.
VEGA thus achieves a balanced advancement in efficiency, programmability, and
scalability for genome sequence alignment.
