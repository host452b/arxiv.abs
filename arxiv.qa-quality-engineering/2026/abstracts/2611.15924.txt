Title: The Distributed Run Manager A C++ Library for Distributed Processing
Authors: Brian Harrawood
ID: 2611.15924
URL: https://arxiv.org/abs/2611.15924

Abstract:
The DistributedRunManager (DRM) is a C++ library for distributing a computing
task among a number of computer systems for parallel processing on a network.
The library was originally designed to accelerate synthetic image production for
tomographic images, but is also a general solution for distributing a software
task across diverse, multiple hardware platforms. The DRM self-configures using
a novel C++ class, the ElectionManager. This class selects a server
cooperatively at runtime and eliminates the need for a priori distribution
configuration. All communication, logging, and fault-tolerance mechanisms are
encapsulated by the DRM, providing a "black-box" interface to the application
developer.
