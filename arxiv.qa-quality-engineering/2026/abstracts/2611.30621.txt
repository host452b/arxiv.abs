Title: AgentBouncer: Defending Software Engineering Agents via Dynamic System-Call Mediation
Authors: Pascal Joos, Michael Pradel
ID: 2611.30621
URL: https://arxiv.org/abs/2611.30621

Abstract:
Software engineering (SE) agents can complete diverse engineering tasks by
interacting with the development environment via tools that access files, run
commands, and download resources. Unfortunately, the same ability that makes SE
agents useful also makes them prone to performing unintended malicious actions
through prompt injections, malicious tools, or supply-chain attacks. Existing
defenses that analyze the agent trajectory may fail to detect such attacks, as
they inspect only the initial prompt and the sequence of tool calls, but not the
actual actions that are executed in the environment. This paper presents
AgentBouncer, a novel runtime enforcement system that prevents SE agents from
performing malicious actions by mediating, and if necessary denying, system
calls that agents trigger via tool calls. The core of AgentBouncer is an LLM
arbiter that judges system calls along two axes, necessity and safety for the
current task. It denies unsafe system calls, and the less necessary a system
call appears, the more certain the arbiter has to be about its safety to allow
it. To manage runtime overhead, preseeded policy rules and hierarchy-aware
caching ensure that the LLM arbiter is only invoked for key decisions. We
evaluate AgentBouncer on a dataset of 340 attacks on the development
environment, covering four attack vectors, combined with benign issue resolution
tasks from SWE-bench Verified. AgentBouncer reduces the attack success rate from
99.41% for an unsupervised agent to 10.59%, which is 18.23-73.53 percentage
points lower than competitive state-of-the-art defenses. At the same time,
AgentBouncer preserves the task success rate of the agent, with only 0.25%
failed benign tool calls. Per benign task, AgentBouncer adds 47 seconds and USD
0.0036 in LLM costs to an unsupervised agent, whereas the closest existing
runtime defense adds 4.5x as much time and 9.6x as much cost.
