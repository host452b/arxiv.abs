Title: From Observation to Explanation: Mechanistic Interpretability of LLM-Generated Code for Principled Repair
Authors: Musfiqur Rahman
ID: 2611.28153
URL: https://arxiv.org/abs/2611.28153

Abstract:
Large language models (LLMs) have transformed software development, yet our
understanding of how they generate code remains critically underdeveloped. We
address this gap by triangulating evidence across three layers. Longitudinally,
autonomous agent-attributed code is statistically indistinguishable from human
code under a semantic modification definition (HR = 1.019, p = 0.490), yet
attracts disproportionately corrective modifications in production (49.1% vs
37.9% human baseline). This finding demands a causal explanation. Empirically,
existing benchmarks overestimate LLM capabilities: models that achieve 84 to 89%
correctness on synthetic tasks attain only 24 to 35% on real-world class-level
code. Behaviourally, detection systems reveal puzzling asymmetries: GPT-3.5 is
far more detectable than modern models (AUC-ROC = 0.96, a 27-point gap), even
though modern models produce mutually similar code structures; yet no single
feature reliably distinguishes AI-generated from human code at the class level,
and the leading commercial detector achieves only 15 to 64% recall. Together,
these findings raise a question that empirical studies cannot answer: why do
LLMs generate code with these properties? This thesis proposes mechanistic
interpretability, a causal token-level circuit tracing, as the bridge between
empirical observation and principled correction. By identifying the transformer
circuits responsible for detectable stylistic signatures, hallucination
patterns, and systematic defects, we aim to drive an agentic repair framework
that intervenes at the causal source of defects rather than patching surface
symptoms.
