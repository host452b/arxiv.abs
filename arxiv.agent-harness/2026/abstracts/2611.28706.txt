Title: SkillLens: An Interactive Human-LLM System for Diagnosing and Refining Agent Skills
Authors: Shuo Yan, Rui Sheng, Xiaoyan Gu, Lian Lian, Chengran Xu, Yifang Wang
ID: 2611.28706
URL: https://arxiv.org/abs/2611.28706

Abstract:
LLM agents increasingly rely on reusable skills, yet maintaining them requires
developers to connect revisions with changes in behavior and task outcomes.
Existing workflows fragment evidence across versions, evaluation cases, and
execution traces. We present SkillLens, an interactive human-LLM system for
diagnosing and refining agent skills. A formative study with five developers and
researchers identified challenges in prioritizing failures, reconstructing case-
level evidence, and preserving context across revisions. SkillLens links
performance changes, case transitions, skill diffs, invocation sequences,
traces, and outputs in a recoverable workflow, while keeping model-generated
explanations and refinements under human review. Through a between-subjects user
study with 20 participants, we show that SkillLens supports developers in
diagnosing and refining agent skills through a more usable and less demanding
workflow than the baseline. These findings highlight the value of linking
version comparisons, case-level evidence, and human-reviewed refinement across
skill iterations.
