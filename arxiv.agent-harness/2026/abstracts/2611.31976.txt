Title: CodeHOI: Code with Agents for Physically Plausible 4D Hand-Object Interaction
Authors: Seonghwan Park, Inho Chang, Min-Gyu Park
ID: 2611.31976
URL: https://arxiv.org/abs/2611.31976

Abstract:
Modeling 4D hand-object interaction (HOI) is fundamental to understanding
manipulation. This requires physics, since hands move objects only by touch and
each material responds differently. Yet existing methods ignore this physics or
simulate only a narrow range of matter. Programs can instead describe any matter
with its physics, but coding agents omit the hand that drives the interaction.
We close this gap with CodeHOI, to our knowledge the first agentic framework
that writes physically plausible 4D HOI as programs. To write one, an Object
Agent first builds each object with the physics of its matter. An HOI Agent then
specifies the hands by their contacts and simulates each kind of matter with an
established physics solver. Finally, an Evaluator Agent checks each result
against physical laws. We also introduce CodeHOI-Bench with 100 reconstruction
and generation tasks across four kinds of matter. With off-the-shelf frontier
models, CodeHOI writes interactions that are plausible for every kind of matter
and remain so when transferred to an independent physics engine. It thereby
enables coding agents to write physically plausible HOI across diverse matter.
