Title: IteraSong: LLM-Guided Iterative Symbolic Music Creation in a Web DAW
Authors: Di Lu, Xinran Zhang, Yan Gao, Yuan Zhang, Xiaoqing Wang, Qingwen Zhou, Xiaobing Li, Maosong Sun
ID: 2611.29225
URL: https://arxiv.org/abs/2611.29225

Abstract:
Music creation is inherently iterative, yet many symbolic generation systems
still center on producing or regenerating isolated outputs. We present
IteraSong, an interactive web-based Digital Audio Workstation (DAW) for LLM-
guided iterative symbolic music creation. Unlike one-shot generation systems,
IteraSong supports a generate-audition-edit-refine loop over a persistent multi-
track project. Users initialize a fully labeled pop draft, then progressively
refine it through natural-language instructions. The LLM maps requests to a
hierarchical action space of editing primitives exposed via Model Context
Protocol (MCP) tools, spanning global, track, section, and bar/note scopes. The
demo enables attendees to edit multi-track compositions in natural language,
apply deterministic and generative edits, and undo/redo changes in real time.
