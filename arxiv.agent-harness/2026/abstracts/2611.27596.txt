Title: Isonomy: Isolating Every Request from Timing Side Channels at Nearly Full-Sharing Throughput in Multi-Instance LLM Prefill
Authors: Bowen Sun, Chaowei Xiao
ID: 2611.27596
URL: https://arxiv.org/abs/2611.27596

Abstract:
Many long prompts share a prefix, and reusing its cached keys and values saves
prefill computation. A cache hit, however, makes the first token arrive earlier
and can reveal that another request used the same prefix, so providers share the
cache only within an account. Under least privilege, even permission to send and
pay for requests should not expose other requests' prompts in the same account.
This matters because agents send unreviewed requests carrying private data,
resellers pool users behind one account, and creden-tials can be stolen. Isonomy
therefore isolates each request by default and lets requests opt into explicit
sharing groups. Rather than give up reuse, it keeps one cache shared across
accounts and hides only hits on prefixes cached outside a request's group. We
target deployments where clients cannot observe one another's load, because
there it suffices to hide these hits in the request's own timing. On three
commercial APIs, our listeners could not distinguish added prefill work from a
short request beyond measurement noise. Built on vLLM, Isonomy's gateway applies
the deployment's routing rule to load and visible cache entries only, which
yields the instance where the request would run if hidden hits missed. On that
instance, the prediction mode estimates when the first token would be ready from
the queue and the visible prefix, and gates its release. The execution mode
instead reserves the work a hidden hit skips and fills it with other requests'
prompts where possible. In direct-probe tests on two, four, and eight instances
with every request isolated, both modes kept the upper bound on a probe's
advantage within measure-ment noise at both prefix lengths. At saturation, the
prediction mode retains 0.98 of unprotected sharing's throughput on two
workloads with account labels, whereas isolation by account retains 0.95, or
0.80 where more reuse crosses accounts.
