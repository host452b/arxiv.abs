Title: Off-the-Shelf Autonomous Agents for Game Playtesting
Authors: Ayush Maniar, Eryk Banatt
ID: 2611.31570
URL: https://arxiv.org/abs/2611.31570

Abstract:
In playtesting games, a human operator is typically required to test most
gameplay elements. In this work we present Buddy, an autonomous game solving
agent which can solve long time horizon objectives in an unseen 3D role-playing
game using off-the-shelf language model systems. Buddy will take actions,
receive feedback on those actions, and pursue a goal across many turns. No
written walkthrough or model training of any kind is required, and we show that
this paradigm holds in a novel environment where the agent must discover
solutions via exploration rather than recalling them from pretraining. We
demonstrate three downstream capabilities: game solving with no provided
walkthrough, logging bug tickets for encountered difficulties, and conversion of
successful agent traces into scripted hierarchical task networks for regression
testing. Unlike existing playtesting solutions, our framework is fully modular:
language models and harnesses can be easily swapped out as capabilities improve
over time.
