Title: Spiking World-Action Models for Robotic Manipulation
Authors: Mingquan Liu, Peng Zhou, Shanming Yao, Shuai Wang, Simo Wu, Malu Zhang
ID: 2611.30041
URL: https://arxiv.org/abs/2611.30041

Abstract:
World action models (WAMs) predict how the world responds to actions and offer a
promising path toward general embodied intelligence, but they are large and run
the network many times per plan, so they are hard to deploy on robots. Spiking
neural networks (SNNs) compute with sparse binary spikes and use additions
instead of multiplications, which saves power. However, existing WAMs use dense
videos as the world state, so a spiking version would spend most of its
computation on the background. We therefore introduce SpikingWAM, the first
spiking WAM, which uses a sparse task skeleton as the world state. Inspired by
biological motor control, which attends only to the key positions of a task, the
Task Skeleton State (TSS) keeps the keypoints of the arm and the task objects,
and a small spiking front end estimates the object keypoints from images. Body
Frame Spike Coding (BFSC) and Grid Coincidence Attention (GCA) keep millimetre
precision, and the Persistent Single Step Readout (PSR) runs the network once
per plan. On the simulated benchmarks LIBERO, LIBERO-Plus and RoboTwin 2.0,
SpikingWAM achieves competitive success rates with far less energy than ANN
methods and surpasses all compared methods on LIBERO-Plus. Real robot
experiments further confirm its effectiveness. These results show that a task
skeleton lets spiking networks implement WAMs at very low energy, offering a new
solution for low power embodied intelligence. Project page:
https://wxqnl.github.io/spikingwam/
