Title: TRAE: Trustworthy Automated ESG Annotation via Multi-Agent Consensus and Confidence Assessment
Authors: Jaeyoung Lee, Misuk Kim
ID: 2611.30035
URL: https://arxiv.org/abs/2611.30035

Abstract:
With the growing demand for ESG disclosure and evaluation, constructing high-
quality datasets for automatically extracting ESG-related information from
large-scale documents has become essential. However, ESG annotation remains
challenging due to strong context dependence, ambiguous label boundaries, and
the need for domain expertise, resulting in high annotation cost and limited
scalability. To address these challenges, we propose TRAE (TRustworthy Automated
ESG annotation), a multi-agent framework for scalable and reliable ESG data
construction. Unlike direct LLM-based annotation, TRAE evaluates annotation
reliability by modeling agreement, confidence, and reasoning consistency among
multiple agents through a structured multi-step reasoning process. Experimental
results demonstrate that TRAE improves annotation performance compared with
existing automated annotation strategies. Furthermore, TRAE supports a hybrid
human-AI annotation strategy that assigns expert labeling only to uncertain
samples, reducing annotation cost while preserving data quality. Using TRAE, we
construct a high-quality ESG dataset containing approximately 20,000 instances
with complete reasoning traces, intermediate agent outputs, and reliability
information to enhance transparency and reproducibility. Overall, this work
provides a practical and scalable framework for trustworthy ESG data
construction. The code and data are publicly available at:
https://github.com/nowzer0/TRAE.
