Title: Tracking and Limiting Unsupported Claim Propagation in Multi-Agent LLM Systems: A Provenance-Aware Framework
Authors: Zijia Cao, Hanqing Dou
ID: 2611.26957
URL: https://arxiv.org/abs/2611.26957

Abstract:
This research examines how unsupported claims change as they move through multi-
agent pipelines. It also examines whether preserving provenance can reduce these
changes. We test both homogeneous and heterogeneous pipelines. Homogeneous
pipelines use the same model across agents, while heterogeneous pipelines use
different models. We compare the baseline with a provenance-aware framework. The
framework passes each claim with its support status, source, evidence and
transmission history. No new evidence is introduced during transmission. We
measure changes in claim meaning, unsupported detail accretion, semantic drift,
and provenance preservation. These metrics show whether the framework limits
unsupported changes as claims pass between agents.
