Title: CANON: Agent-Assisted Construction of Canonical Differential Equations for Feynman Integrals
Authors: Dong-shan Jian, Yuanche Liu, Yan-qing Ma, Bo-xuan Shi, Yu Wu, Zihao Wu, Yang Zhang
ID: 2611.33100
URL: https://arxiv.org/abs/2611.33100

Abstract:
The construction of canonical basis is an important procedure in the calculation
of multi-loop Feynman integrals via the canonical differential equation methods.
Currently, there are various different methods for this purpose. Among them, no
single method is universally applicable. Thus, obtaining a valid basis often
requires repeated attempts and verification. In this paper, we present CANON, an
agent-assisted framework designed to make this search-and-verification process
more convenient and more efficient. In this workflow, the agent selects methods
and calls the corresponding tools to revise the basis proposal or the associated
differential-equation system. Independent programs then verify whether the
agent's result is valid and ask the agent to retry if verification fails. This
framework contains a specific state-management tool to supports long-range basis
searching works which requires multiple sub-agents. Its modular architecture
enables future extensions to the framework itself. In this paper, we demonstrate
this framework by applying it to some two-loop and three-loop integral families.
