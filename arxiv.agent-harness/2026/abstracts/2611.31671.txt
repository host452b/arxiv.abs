Title: AeroPoint: Agentic AI for Intent-Driven Point Cloud Inspection in UAV-Edge Systems
Authors: Reza Farahani, Zoha Azimi, Naser Hossein Motlagh, Christian Timmerer, Arda Goknil, Sagar Sen, Schahram Dustdar
ID: 2611.31671
URL: https://arxiv.org/abs/2611.31671

Abstract:
Unmanned Aerial Vehicle (UAV)-based Light Detection and Ranging (LiDAR)
inspection generates dense point clouds that strain onboard computing and
wireless bandwidth. Intent-based inspection allows operators to request objects,
attributes, and spatial relationships through natural language. Answering these
requests requires trans- lating intent into spatial queries and retrieving
relevant evidence under UAV processing and communication constraints. This
article presents AeroPoint, an agentic AI system combining onboard point cloud
processing and knowledge graph construction with Large Language Model
(LLM)-based retrieval planning at a ground edge server. The LLM translates
inspection questions into structured requests, which the UAV executes to return
selected graph evidence for answer generation. We evaluate the prototype in a
power line inspection case study using 150 TS40K UAV LiDAR scenes and profile
processing costs on NVIDIA Jetson Nano hardware. Retrieval experiments use
graphs constructed from dataset-provided ground-truth semantic labels.
Experimental results show that transmitted payload decreases from 3700 KB for
complete point clouds to 3.1 KB for retrieval responses, while evaluated LLM
routers achieve the highest graph retrieval completeness for relational queries.
