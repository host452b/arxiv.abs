Title: Action Windows Are Inherently Temporal: A Benchmark for Time-Sensitive Robotic Manipulation
Authors: Haoxiang Zhan, Haoqin Hong, Congcong Zhu, Jingrun Chen
ID: 2611.29558
URL: https://arxiv.org/abs/2611.29558

Abstract:
Vision-language model (VLM) agents have surpassed learned-policy baselines on
existing robotic manipulation benchmarks. However, these agents still struggle
with time-sensitive everyday tasks that existing benchmarks for VLM agents cover
only partially. In these tasks, evolving physical processes create finite
windows for successful intervention. These action windows are inherently
temporal and impose a shared time budget on decision making and physical
execution. Coordinating intervention within this budget requires agents to
determine when the window opens. We introduce AWAIT, a simulation benchmark that
evaluates task completion within action windows while accounting for decision
and execution time. Our evaluation reveals difficulties in recognizing window
onset and shows that successive decisions and movements can exhaust an action
window even when each decision takes less than the window duration. Project
page: https://eyja42.github.io/await-site/.
