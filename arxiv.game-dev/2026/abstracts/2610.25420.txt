Title: Adaptive Cyber-Defense for Evolving Attacker Capabilities using Reinforcement Learning and Behavior Trees
Authors: Nicholas Potteiger, Ankita Samaddar, Xenofon Koutsoukos
ID: 2610.25420
URL: https://arxiv.org/abs/2610.25420

Abstract:
Autonomous cyber-defense agents trained using reinforcement learning (RL) are
increasingly adopted for defending enterprise computer networks. However,
existing approaches may become brittle as attacker capabilities evolve and
enable new attack strategies. In this work, we study the problem of adapting
defender policies learned in CAGE Challenge Scenario 2 (CC2), a benchmark
enterprise network defense scenario, to an extended network scenario with new
attacker capabilities represented by new attacker actions. Effective attack
strategies that leverage new actions are initially unknown, and therefore
attacker policies must be learned before defender adaptation can occur. To
address this challenge, we develop adversarial RL (ARL) with behavior trees
(ARLBT), which uses reward behavior trees (RBTs) to define progression-based
reward functions and condition attacker policies on RBT execution. The proposed
RBT incorporates the new attacker actions into structured attack strategies
while leveraging parallel execution to generate rewards across multiple network
nodes simultaneously. We evaluate ARLBT for learning attacker policies against
two baseline defender policies across network scenarios with different sets of
new attacker actions and compare against multiple attacker baselines. The
results demonstrate that ARLBT improves attacker success compared to ARL using
the original CC2 reward function and that conditioning policies on RBT execution
can improve sample efficiency. We further show that defender policies can be
adapted against the learned attackers, improving robustness to attacks that
leverage new attacker actions.
