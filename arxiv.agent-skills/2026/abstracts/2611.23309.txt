Title: Repository-Grounded Rubrics for Execution-Free Evaluation of Coding Agents
Authors: Matej Gerek, Danylo Zahorulko, Samuel Budai, Chris Rupley, Thierry Donneau-Golencer
ID: 2611.23309
URL: https://arxiv.org/abs/2611.23309

Abstract:
Coding agents are usually evaluated by running task-specific tests, but tests
may be missing or incomplete, and running them requires a working environment
for each repository. We adapt agentic rubrics, introduced for selecting among
candidate patches, into an execution-free measure of how far a patch satisfies a
task's requirements. An agent explores the repository before the change and
writes weighted binary criteria, and a judge without tools scores a diff by the
weighted share of criteria it satisfies. We validate the ordering this score
produces against test outcomes on SWE-bench Verified, using 7,291 labeled
patches from fifteen systems. Within the 400 tasks that have both resolved and
unresolved patches, the mean per-task AUROC is 0.826 (0.838 on tasks not used to
tune the rubric-generation prompt), and ranking systems by their failing patches
closely agrees with ranking them by resolve rate (Spearman 0.968). Case analyses
trace disagreements to tests that do not match the task, execution-blocking
defects that the textual assessment misses, and errors in criteria or verdicts.
The validation does not establish absolute score magnitudes or requirement
satisfaction beyond agreement with tests, but rubric scores could complement
tests where tests or execution environments cannot be assumed.
