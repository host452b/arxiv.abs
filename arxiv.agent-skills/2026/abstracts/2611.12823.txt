Title: Coding Agents in KVM: Practical Containment and User Control with Limited Resources
Authors: Yutaka Nagashima
ID: 2611.12823
URL: https://arxiv.org/abs/2611.12823

Abstract:
Coding agents often need broad authority for productive development work, but
granting that authority can expose users' data and infrastructure. Off-the-shelf
cloud workspaces can help contain agent activity, but reliance on provider-
specific platforms can lead to vendor lock-in and reduced user control.
Researchers and engineers must therefore balance agent autonomy, enforced
containment, and user control within available financial, computational, and
human resources. We analyze these trade-offs and present KVM-Agent, an open-
source implementation that automates most setup and provisioning steps. It gives
agents broad authority inside replaceable Ubuntu VMs while keeping host
administration outside those VMs and supporting multiple coding-agent
applications, model services, and remote job delegation. The approach retains
familiar workflows and user choice at the cost of VM resources, maintenance, and
residual risks from secrets accessible inside the VMs and permitted network
access.
