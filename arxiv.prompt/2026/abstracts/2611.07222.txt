Title: SPILLWAY: Separating Target Admission from Sanitization to Defend Tool-Using Agents against Prompt Injection
Authors: Woosang Lim, Yeseul Chang, Jaewoo Lee
ID: 2611.07222
URL: https://arxiv.org/abs/2611.07222

Abstract:
Tool-using agents act on email, files, and payments, so an instruction hidden in
a web page or a shared document can make an agent send data or money to an
attacker. Many runtime defenses put a language model on the decision that lets
an action through, so the decision depends on a model that may read the
attacker's text and adds model calls to every step. Provenance defenses keep the
model off the final check but need a model to plan or route each task first.
Where an action goes can instead be read from the tools' typed returns: an
email's sender or a payment's account arrives in a typed field, while injected
instructions arrive as free text. SPILLWAY turns this observation into a
deterministic floor with no per-task plan. The check admits a call when each
target value that appears in tool output but not in the user's task was returned
by a read-only tool in a typed field or is covered by a fixed delegation rule. A
deterministic sanitizer removes instruction-like regions its fixed rules match
before the model reads them and retains the removed spans as evidence, and a
local judge may restore a refused call, never one whose target lies in the
removed text. Across three backbones, and seven task suites on one of them, the
standard injection template (AgentDojo's important_instructions) never redirects
an action to an attacker's target under SPILLWAY. Across 12 AgentDojo cells,
SPILLWAY leads tested defenses in mean under-attack utility and composite
scores. A forged chat template also produces a raw zero, mean attack success
under a released reinforcement-learning attacker stays below one percent, and
SPILLWAY reaches this floor with no defense-triggered backbone re-run and almost
no added model call. As personal AI agents act on users' email, files, and
payments, SPILLWAY gives them an auditable refusal floor on where their actions
go that keeps them useful and holds across backbones.
