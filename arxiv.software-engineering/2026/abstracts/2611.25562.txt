Title: AZOWL AgentOps: Task-Scoped Governance for Deployed Agent Applications
Authors: Taeoh Hong
ID: 2611.25562
URL: https://arxiv.org/abs/2611.25562

Abstract:
AZOWL AgentOps provides shared governance for deploying agents and delegating
work to them. Human and agent senders can exchange messages or explicitly
delegate a business task. Accepted work has a stable identifier that links the
sender's authority, the assigned runner, any required approval, and result
evidence. The default enrolled customer PC profile is read-only. We compare
AZOWL components with a configured LangGraph application in 28 synthetic runs
across four paired pilots. Original AZOWL services checked work admission,
recipient routing, and workflow prerequisites in isolated tests. The configured
LangGraph application supplied business task and dispatch records in application
code. Both configurations recorded zero business tasks in dialogue, rejected
unauthorized agent handoffs, and issued zero writes when an approved delivery
address changed. AZOWL's scope gate, exercised as a component, requested
approval again on the same task. A product probe reused one registered provider
across two workflows and checked prerequisite enforcement for ticket-task
submission. The paired protected writes, including ticket creation, used mock
providers. Of two deployed PC inventory reads with verified receipts, we traced
the 0.6.57 run from submission through runner pickup and tool execution to the
receipt, with matching local and central artifact hashes. A separate deployed
GRC audit followed an operator-driven ticket lifecycle on sample records.
