Title: Comparing WeChat and Telegram MiniApp Security Architectures: Toward Cross-Platform Analysis
Authors: Luca Ferrari, Billel Habbati, Luca Verderame
ID: 2611.13965
URL: https://arxiv.org/abs/2611.13965

Abstract:
MiniApps are increasingly central to super-app ecosystems, yet architectural
differences complicate the transfer of security analysis techniques across
platforms. Existing WeChat analyzers rely on packaged applications and platform-
specific APIs, limiting their direct applicability to Telegram's web-based
MiniApps. We present a qualitative comparison of WeChat Mini Programs and
Telegram MiniApps, grounded in official documentation, prior research, and
manual analysis of a specific Telegram Android source revision. Using a shared
taxonomy of security controls, assets, and threat sources, we examine execution
environments, communication paths, and trust boundaries. WeChat provides a
dedicated MiniApp runtime; Telegram combines web execution with host controls.
Both retain developer responsibilities for backend authentication and resource
authorization. Two worked examples derive requirements for cross-platform
analysis: distinguishing credential roles and validation boundaries, and
associating host capabilities with concrete execution contexts and permission
handlers. These findings inform future automated analysis without ranking the
ecosystems by security or claiming validated vulnerability detection.
