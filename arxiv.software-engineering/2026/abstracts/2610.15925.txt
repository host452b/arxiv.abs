Title: GarageWorks: A Shared Testbench Abstraction for Software Simulation and FPGA Testing
Authors: Kazutomo Yoshii
ID: 2610.15925
URL: https://arxiv.org/abs/2610.15925

Abstract:
GarageWorks is a lightweight FPGA testing framework that enables the same cocotb
testbench to be used for both software RTL simulation and FPGA-accelerated
hardware simulation. A shared abstraction hides backend-specific interfaces,
while synthesizable Advanced eXtensible Interface (AXI) dispatchers provide
design-under-test (DUT)-specific control and test operations on the FPGA.
GarageWorks is intended for rapid bare-metal testing of standalone designs and
on-chip processing logic for scientific sensors, rather than full SoC-level
prototyping. The framework has been validated on AMD Alveo V80 FPGAs with
several internal designs and provides initial support for AI-assisted generation
of DUT-specific test components.
