Title: DAiSy: Online Data Selection by Adaptive Utility Estimation for LLM Pretraining
Authors: Simin Fan, Martin Jaggi
ID: 2611.32294
URL: https://arxiv.org/abs/2611.32294

Abstract:
Model-aware online data selection prioritizes the training documents that
contribute the most given the model's current state. Existing online selectors
rank candidates upon gradient-based data utility scores, which requires the full
forward-backward pass of the main model on every candidate document. Scoring
each document therefore pays as much as training on it, yet only a small
fraction is used for the real model update. We introduce DAiSy, a lightweight
linear auxiliary model that learns to predict data utility scores from frozen
document embeddings, which eliminates the computation overhead and
infrastructure burdens. The linear estimator is updated alongside the main
language model, fitting to the exact gradient-based utility scores obtained from
the backward pass of regular training steps. Consequently, scoring a candidate
requires only a linear transformation, bypassing the costly gradient-alignment
computation. We demonstrate its effectiveness and efficiency for LLM pretraining
in English and multilingual scenarios, with various steering target designs. The
improvements from DAiSy can consistently survive the instruction-tuning phase.
