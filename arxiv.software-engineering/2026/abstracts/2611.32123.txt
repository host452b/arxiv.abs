Title: Verifying Type Soundness for Nontransitive Information Flow Security
Authors: Chenyi Zhang
ID: 2611.32123
URL: https://arxiv.org/abs/2611.32123

Abstract:
We present a machine-checked soundness proof of a type system for the
nontransitive noninterference (NTNI) information flow security property in an
imperative programming language using Dafny. The original formulation of NTNI
was developed for a functional programming language augmented with memory access
operators, where security policies are expressed as coarse-grained information
flow constraints over component-based software systems. Although subsequent
research has extended NTNI type systems in various directions, to the best of
our knowledge, no prior work has established a machine-checked soundness proof
for type-enforced NTNI. As a result, the correctness of existing NTNI
enforcement mechanisms has not been formally verified with a high degree of
assurance.
