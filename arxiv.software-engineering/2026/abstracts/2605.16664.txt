Title: Optimizing an IDE for an Evolving Language Ecosystem
Authors: Adam Welc, Todd Nowacki, Dario Russi, Cameron Swords, Timothy A. K. Zakian
ID: 2605.16664
URL: https://arxiv.org/abs/2605.16664

Abstract:
This paper describes a strategy for developing a high performance and feature-
rich IDE for an evolving smart contract language ecosystem. Our target is Move,
a programming language for the Sui smart contracts platform. The strategy we
chose to support the Move language ecosystem utilizes Language Server Protocol
(LSP) and it is based on the already existing "core" language machinery, in
particular the core language compiler. We discuss alternatives we considered, as
well as the evolution of our infrastructure that was necessary to keep up with
the growth of the language ecosystem, particularly with respect to optimizations
(and their impact) that needed to be implemented to accommodate this growth. We
conclude with lessons learned during the IDE support development process that we
hope will be beneficial for others attempting to follow a similar path.
