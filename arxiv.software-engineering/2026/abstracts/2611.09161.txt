Title: GreyZone: Production-quality Agentic Application Threats
Authors: Ruoyu Zhou, Shuyao Jiang, Haifeng Ruan, Abhik Roychoudhury
ID: 2611.09161
URL: https://arxiv.org/abs/2611.09161

Abstract:
Agents are increasingly deployed across domains such as coding, banking, and
commerce. Their ability to invoke tools and change application state makes
security testing important for reliable deployment. Although agent security has
been studied through various adversarial testing approaches, benchmarks grounded
in production agent environments remain limited. We introduce GreyZone, a
benchmark for evaluating automated red-teaming services against real-world agent
applications. Unlike benchmarks such as AgentDojo, which primarily evaluate
subject agents under attack, GreyZone evaluates services' ability to generate
and deliver attacks that cause verified security-policy violations. We select
independently developed, open-source agent applications with security boundaries
concerning access permissions, confidentiality, and action authorization. These
applications expose diverse attack surfaces, including those arising from multi-
agent interactions and multimodal inputs. By grounding evaluation in application
environments that preserve production-relevant workflows and independently
verifying outcomes, GreyZone supports research on automated agent security
testing. Specifically, we present two preliminary case studies using Promptfoo
on Letta Code and Clawith to examine attack delivery, agent behavior, and
verified outcomes. We release the benchmark, including subject agents and attack
surfaces for each application, to support further research on agent testing
methods.
