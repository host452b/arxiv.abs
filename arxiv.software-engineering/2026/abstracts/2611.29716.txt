Title: Fin-RSI: A Unified Library of Financial Skills, Checks, and Self-Improvement for LLM Agents
Authors: Wanghao Ye, Shwai He, Sihan Chen, Yiting Wang, Bowei Tian, Guoheng Sun, Ziyi Wang, Ziyao Wang, Yexiao He, Zheyu Shen et al.
ID: 2611.29716
URL: https://arxiv.org/abs/2611.29716

Abstract:
As large language models (LLMs) become more capable, financial agents need tools
they can readily discover and use. Yet financial software is fragmented across
libraries with different interfaces and conventions, making it difficult to
build reliable agent workflows. We present Fin-RSI, a unified Python library of
financial skills, checks, and self-improvement designed for LLM agents. It
brings together tools for market analysis, forecasting, portfolio construction,
and trading research through shared interfaces across models and agent
frameworks. Agents can find suitable tools from natural-language requests, reuse
tested implementations, and improve generated programs through checking and
feedback. Developers can extend the library with new tools without rebuilding
integrations for each model. Across 20 open-weight models on six trading-
position tasks, tool discovery increased the proportion of episodes producing
valid programs from 9.7% to 29.2%; for models with at least 14 billion
parameters, it rose from 23.6% to 64.6%. We release the library and benchmark as
a shared resource for the community and plan to expand its tools and task
coverage as financial agents evolve.
