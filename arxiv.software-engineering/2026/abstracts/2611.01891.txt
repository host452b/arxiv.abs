Title: Interface Quilt: Modifying Applications with Computer Use Agents and Generative UI
Authors: Leping Qiu, Jo Vermeulen, Tim Zindulka, George Fitzmaurice, Fraser Anderson
ID: 2611.01891
URL: https://arxiv.org/abs/2611.01891

Abstract:
Modifying an existing application is difficult when it does not provide
programmatic access for that change. Recent advances in computer-use agents
(CUAs) enable richer understanding and operation of existing interfaces, while
generative UI (GenUI) makes it practical to generate new ones. We examine how
these advances expand software modification through a design space of what can
be changed and a framework for how modifications can be implemented. We then
introduce Interface Quilt, a system that combines CUAs and GenUI to generate
interface patches, which are new interfaces displayed over an existing
application to modify its presentation, interaction, and capabilities. Through
demonstrations across a variety of applications, we show that interface patches
support a range of modifications without source code, APIs, or accessibility
data.
