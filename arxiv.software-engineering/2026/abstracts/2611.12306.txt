Title: ExoStack: A Modular and Reconfigurable Software Framework for Wearable Robotics Using ROS 2
Authors: Debadrata Sarkar, Upamanyu Ray, Soumen Sen, Aman Arora
ID: 2611.12306
URL: https://arxiv.org/abs/2611.12306

Abstract:
Wearable robots depend on a software chain that links body-worn sensing to gait
interpretation, assistance generation, and actuation. Personalization further
requires each measured response to remain associated with the assistance
parameters that generated it. This paper presents ExoStack, a modular ROS 2
framework for implementing that chain across embedded hubs and a host computer.
Its Embedded Sensing and Actuation (ESA) library configures ESP32 boards as
microROS sensing and actuation hubs. ExoCore supplies multi-hub synchronization,
gait-event detection, profile generation, motion planning, cost evaluation, and
human-in-the-loop (HIL) optimization as configuration-instantiated nodes. The
PASE desktop application edits configurations, launches the processing stages,
and visualizes ROS 2 topics. Hardware drivers and algorithm plugins can be added
through defined interfaces without modifying the generic processing nodes. We
characterize hub and planner timing on three embedded computers and demonstrate
reuse on two pneumatic exosuits.
