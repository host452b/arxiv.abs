Title: A DIY DPDK Software Router for Networking Education
Authors: Sebastian Gallenmüller, Stefan Lachnit, Manuel Simon
ID: 2610.29625
URL: https://arxiv.org/abs/2610.29625

Abstract:
High-performance packet processing frameworks, such as the Data Plane
Development Kit (DPDK), are widely used in modern network systems, yet they are
rarely integrated into networking curricula. As a result, students often lack
exposure to the performance considerations and low-level design choices that
shape real-world packet processing systems. We describe a semester-long course
project in which students implement a do-it-yourself (DIY) software router using
DPDK in a master-level computer networking course. The project guides students
through the design and implementation of a multithreaded router, the development
of a routing table data structure, and the evaluation of forwarding performance
using standard benchmarking tools. We present the project structure and the
virtualized infrastructure used to support classes of realistic size. Based on
several iterations of the course and survey feedback from participating
students, we discuss the observed workload, learning outcomes, and challenges of
teaching high-performance packet processing. We release the project material and
scripts to recreate the infrastructure, enabling reuse and further refinement by
the community.
