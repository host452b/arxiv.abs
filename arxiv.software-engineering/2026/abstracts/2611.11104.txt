Title: Tracing MCP Security Vulnerabilities: Constructing and Analyzing an MCP Security Vulnerability Dataset
Authors: Xu He, Sagar Patel, Shu Wang
ID: 2611.11104
URL: https://arxiv.org/abs/2611.11104

Abstract:
As a core protocol for integrating large language models (LLMs) with external
data sources and tools, the Model Context Protocol (MCP) has quickly become a
key interface in emerging AI agent systems. As the MCP ecosystem expands,
reported vulnerabilities have also increased, creating a growing software-
security attack surface. However, MCP vulnerability information remains
scattered, noisy, and difficult to study systematically. This paper addresses
that gap by constructing a curated MCP vulnerability dataset from CVE
disclosures. Starting from 119 MCP-related records retrieved through February
2026, we filter unrelated cases out and obtain a validated snapshot of 24 MCP
vulnerabilities. Our filtering methodology explicitly addresses acronym
ambiguity and achieves 96.7% inter-rater agreement on a sampled exclusion audit
while retaining all known high-severity MCP cases identified in public
advisories. Using this initial dataset snapshot, we find that 87.5% of validated
vulnerabilities are Critical or High severity, and that injection and path
traversal vulnerabilities account for 66.7% of cases. We further identify
recurring issues involving insufficient input validation, inadequate access
control, and protocol-level security gaps. Through six representative case
studies, we illustrate common exploitation patterns and map them to practical
defenses. We release the dataset, reproducibility tooling, and a sustainable
maintenance workflow as a foundation for future MCP security measurement,
benchmarking, and defense research.
