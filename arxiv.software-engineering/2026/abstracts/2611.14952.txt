Title: JoyFrontBench: Evaluating Front-End Coding Agents through Goal-Oriented Acceptance Contracts
Authors: Xiaoyi Qiao, Yicheng Wang, Jianan Lin, Xiaoyang Ji, Dongyi Lv, Yidan Huang, Shi Suo, Shiying Fan, Nan Duan, Jiaqi Wang
ID: 2611.14952
URL: https://arxiv.org/abs/2611.14952

Abstract:
Front-end coding agents are expected to produce applications that fulfill user
goals, yet high task scores can coexist with failures in essential workflows.
Evaluating these agents therefore requires an explicit distinction between
partial implementation and application success. We introduce JoyFrontBench, a
benchmark that makes this distinction through goal-oriented acceptance
contracts. Each contract identifies core tasks and mandatory criteria before
generation: a core task passes only when all mandatory criteria are satisfied
and a shared completion threshold is met, while application success requires
every core task to pass on the same operational artifact within a single run.
Derived from practitioner requirements, JoyFrontBench comprises 100 front-end
development problems, 764 tasks, and 2,596 atomic criteria, with reviewed
annotations linking user goals to core tasks and evidence requirements. The
evaluation framework combines evidence-grounded judgments with deterministic
record auditing and fixed scoring rules, preserving graded task assessment
alongside explicit core-task and application-level acceptance. We evaluate five
coding models under two agent harnesses, OpenHands and OpenCode, on the
70-problem test set; the remaining 30 problems form a public set for validation
and diagnostic analyses. Under OpenHands, the mean Average Task Score (ATS)
across models is 87.69%, while the mean Application Success Rate (ASR) is
51.52%. Further analyses reveal changes in model rankings across harnesses and
variation in application success across repeated runs. These findings highlight
the limitations of aggregate task scores in characterizing application success
and motivate explicit assessment of core-goal fulfillment alongside graded task
performance.
