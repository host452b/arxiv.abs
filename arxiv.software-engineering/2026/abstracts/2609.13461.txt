Title: Rethinking Software Development as a Self-Adaptive Socio-Technical System
Authors: Javier Cámara
ID: 2609.13461
URL: https://arxiv.org/abs/2609.13461

Abstract:
Agentic AI is substantially shortening the timescale at which development
context (e.g., goals, evidence, uncertainty, and risk) evolves. However, human-
agent organization across development tasks is typically treated as fixed, which
is problematic because development configurations may become suboptimal as the
development context changes. We propose viewing software development as a self-
adaptive socio-technical system in which both the software project and the
development configuration (participants, responsibilities, authority,
information, and verification) adapt as the development context evolves. This
yields two coupled forms of adaptation: evolving the software and reconfiguring
how subsequent engineering is performed. We illustrate the idea with a proof of
concept, outlining challenges and future plans.
