Title: Software Change Request in AI-Synthesized Software Evolution
Authors: Muhammad Nadeem, Khurram Shahzad, Muhammad Nadeem Majeed
ID: 2611.00294
URL: https://arxiv.org/abs/2611.00294

Abstract:
Mobile app stores are a rich source of user feedback containing many change
requests, bug reports, improvement suggestions, etc., relevant to the post-
deployment modification of software. However, it is challenging to manually
translate this free format data to actionable change requests (SCRs). This
review presents studies that have applied rule-based techniques, traditional ML
approaches, topic modelling, hybrid approaches, and a few deep learning
approaches. The data sets used range from small annotated sets to millions of
reviews. However, there is inconsistency in the names, availability, annotation
guidelines and sampling methods used across different studies. Many studies use
Bag-of-Words and TF-IDF, while Naïve Bayes, Support Vector Machines, Decision
Trees and Random Forest are frequently applied. Precision, Recall and F1-scores
are commonly used for evaluation; however, results and experiments are not
easily comparable. Some tools have been developed such as SURF, ARDoc,
ChangeAdvisor, ALERTme, AUREA, DIVER, ACRM and KEFE to partially automate the
classification, summarization, topic detection and traceability. This review
shows that there is still a lack of consistency in the data sets used,
reproducible annotation, generalization across languages and domains, contextual
modelling, interpretability and integration with maintenance activities. This
review provides a consolidated view and taxonomy to provide a research agenda to
support more reliable AI enabled software evolution.
