Title: Agent Authenticator: Passkey-Grade, Hardware-Bound Authentication for AI Agents
Authors: Harish Santhanalakshmi Ganesan
ID: 2611.19536
URL: https://arxiv.org/abs/2611.19536

Abstract:
AI coding agents now push code, publish packages, call model APIs and operate
cloud resources on behalf of developers. They authenticate to these services
with the same bearer secrets humans use, personal access tokens, API keys and
package-registry tokens, stored where the model, its subprocesses and any co-
resident malware can read them. Incidents in 2025 and 2026, including prompt-
injection attacks on coding agents and self-propagating supply-chain worms, show
that this arrangement fails in predictable ways. Passkeys solved the analogous
problem for humans, but they require a human gesture on every use and cannot be
operated by an autonomous process. We present the Agent Authenticator, a design
that gives agents passkey-grade authentication properties: per-service hardware-
bound keys, no shared secrets, origin binding enforced by the runtime rather
than the model, normalized attestation of the execution environment, human-
signed scoped mandates, and cross-device human approval for high-risk actions.
The same protocol serves agents on developer laptops and in cloud enclaves, and
it deploys as a profile over existing mechanisms, MCP authorization, OAuth token
exchange including the Identity Assertion JWT Authorization Grant, git and SSH,
rather than as a new identity system. The authenticator also produces a signed,
hash-chained record of each action it authorizes. We analyze the design against
a threat model centered on prompt injection and same-host compromise, map it
onto five documented incidents, and discuss its limits.
