Title: Reliability-aware AI Agent Execution in Collaborative Edge Computing: A World Model Approach
Authors: Xiangchun Chen, Jiannong Cao, Longxiang Gao, Xiaoming Wu, Yusheng Ji
ID: 2611.32520
URL: https://arxiv.org/abs/2611.32520

Abstract:
Collaborative edge computing supports AI agent applications by distributing
execution across heterogeneous user-controlled devices with limited resources.
This paper studies reliability-aware AI agent execution under node failures and
wireless disruptions. These disruptions can make agent execution state
unavailable or inconsistent, forcing recovery or recomputation that consumes the
remaining deadline budget. Maintaining recoverable execution states can
therefore improve request completion before deadlines. We formulate an online AI
agent execution management problem that jointly selects resource allocations,
state protection actions, and recovery targets to maximize the expected task
success rate subject to resource, compatibility, and deadline constraints. We
develop a world model that jointly captures evolving agent workflows and
recoverable execution state under candidate management actions, accounting for
node reliability, network conditions, and resource availability. The model
enables the controller to simulate future execution and recovery trajectories
under candidate actions and estimate their effects on execution progress and
task completion before deadlines. We then employ world model-based model
predictive control (WorldMPC) with Monte Carlo rollouts to jointly optimize
resource allocation, state protection, and recovery decisions for long-term
reliable agent execution under the dynamic environment. We evaluate the proposed
approach on the simulation and real-world testbed using real-world and synthetic
datasets. Experimental results show that WorldMPC improves task success rate
over baselines in both simulation and real-world testbed.
