Title: VABAR: A Variational Automation Benchmark for Agentic Robotics
Authors: Shuangyu Xie, Kaiyuan Chen, Uksang Yoo, Xinyue Zhu, Meadow Shen, Jaimyn Drake, Eugen Solowjow, Lionel Gulich, Alexander Millane, Rafael Cathomen et al.
ID: 2611.06881
URL: https://arxiv.org/abs/2611.06881

Abstract:
For robots to operate reliably in commercial and industrial applications, they
must persistently perform specific tasks with known variations in object shape
and pose. We call this Variational Automation (VA) to differentiate these
settings from fixed automation. Inspired by recent papers on Agentic Robotics,
where pretrained LLM and VLM coding agents combine interpretable robot
programming with the open-world adaptability of model free policies, we propose
a general set of agentic robotics benchmark design criteria that includes
accessibility, repeatability, diversity, relevance to agentic robotics and
practical applications, physical realizability, resistance to benchmark
saturation, and computational efficiency. We instantiate these principles in six
manipulation task classes spanning industrial, medical, and infrastructure
applications: tool sorting, tool hanging, gear meshing, syringe packing, cable
insertion, and cable routing. We introduce the Variational Automation Benchmark
for Agentic Robotics (VABAR), an open, easily replicable, simulation-based
manipulation benchmark to systematically evaluating agentic robotics systems.
Built fully on open-source tools, VABAR features detailed implementations using
the Newton physics engine, standardized task variations, difficulty tiers,
success metrics, and a library of 33 generalizable skills with human-authored
programmatic reference solutions. We provide initial baseline evaluations using
an open agentic manipulation harness, Graph-as-Policy (GaP), and Isaac Lab
Arena.
