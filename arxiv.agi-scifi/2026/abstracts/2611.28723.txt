Title: AERIN: Aerial Instance Navigation with a Visual World Model
Authors: Zhenzhen Jiao, Rui Tian, Zhineng Chen
ID: 2611.28723
URL: https://arxiv.org/abs/2611.28723

Abstract:
Searching from high altitude and navigating to a target instance specified by a
reference image is a common application for UAVs. In such tasks, high-altitude
observations provide broad ground coverage for efficient search, but targets
occupy fewer pixels, making instance verification and action selection more
difficult. We present AERIN, a visual world model that uses action-conditioned
prediction to guide the UAV toward the target while adjusting its viewpoint to
obtain higherquality observations for subsequent instance verification.
Highaltitude navigation requires fine-grained target details and scene context
relevant to visibility, but repeatedly predicting dense visual representations
of this information is computationally expensive. AERIN addresses this challenge
with a compact, fixedsize, target-conditioned latent state that separately
represents both for efficient action evaluation. Experiments demonstrate that
AERIN outperforms the evaluated baselines in target approach and observation
quality, while requiring substantially less decision time than similar world
models.
